{% load static i18n %}{% comment %} Structured data, only for the pages that ask to be indexed. This is what lets a search engine treat the brand as one entity rather than ten unrelated URLs: a name, a logo, the languages spoken, the country served, and a phone number a person can call. Guarded by `indexable`, so the pay page and the merchant portal never describe themselves to anyone. Everything here must be true and must match what the page says. Marking up a claim the page does not make is structured-data spam by Google's definition, and it loses the rich result rather than winning one. Deliberately NOT here: FAQPage. The answers live in faq.html as translated strings, so generating the markup would mean a second copy that drifts out of step with the first — and since 2023 Google shows FAQ rich results only for government and health sites, so a commercial site gets nothing for the risk. {% endcomment %}{% if indexable %}{% endif %}
